01 / THE PROJECT

ABOUT THE GAME

"Get Keke Out the Club!" is an interactive game where the player has to help Keke escape the club by using sound. By making noise near the microphone, the player controls Keke's movement from side to side while avoiding incoming obstacles. The game explores how sound can be transformed into movement in a playful and unexpected way.

05 / TRANSPARENCY

HOW I USED AI

Tool: Claude Sonnet 5.5 (Anthropic) We used AI to generate parts of the game code, for example the volume calculation and the calibration timer. We also asked it to explain code we didn’t understand. It also helped to create this web page to simulate our game. An example of a prompt we sent was "simplify fftSize so I can understand it". My co-creator Amira Smith and I created the whole idea. All the prompts sent to AI had a direct intention to achieve our planned goals for the game. When the AI created the code, we personalized it to our taste and goals. Primarily we adjusted CSS and HTML, but we also fixed functions like smoother movement by evening out the volume. We tested everything in the browser to see that it worked. We found that the AI sometimes wrongly assumed how the game worked, for example it made the character move vertically.
