01 / THE PROJECT

ABOUT THE GAME

"Get Keke Out the Club!" is an interactive game where the player has to help Keke escape the club by using sound. By making noise near the microphone, the player controls Keke's movement from side to side while avoiding incoming obstacles. The game explores how sound can be transformed into movement in a playful and unexpected way.
